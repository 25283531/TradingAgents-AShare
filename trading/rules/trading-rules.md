# A 股 2～5 交易日短线规则

本目录是策略执行的唯一规则来源。研究角色可以提出观点，但确定性规则负责筛选、评分和最终动作。

## 流程

市场 → 资金 → 行业 → 政策 → 新闻 → 情绪 → 候选 → Bull → Bear → Debate → Judge → Decision → Risk。

事实与推论分开记录，证据使用 A（官方/交易所/公司披露/可靠实时数据）、B（权威媒体或行业数据）、C（评论）、D（未经验证的传闻）分级。D 级只能作为线索。

## 硬条件

价格不高于 7 元，成交额原则上不低于 1 亿元；个股强度不弱于所属行业；资金不能持续大幅流出；不处于连续涨停模式；不严重超买；必须存在可证伪的 2～5 日逻辑。缺少关键字段时不能用猜测填充，默认不通过。

## 评分与动作

市场 15、行业资金 15、个股资金 15、相对强度 15、流动性 10、新闻政策 10、情绪 10、技术结构 5、预期差 5，总分 100。80 分以上强关注，70～79 分等待买点，60～69 分观察，低于 60 分淘汰。高分仍需满足实时触发条件。

最终动作只能是 `BUY`、`WAIT`、`OBSERVE`、`NO TRADE`。风险拥有一票否决权。
